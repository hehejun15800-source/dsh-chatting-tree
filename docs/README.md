# 截图

把界面截图放到这里，并在 `README.md` / `README.zh.md` 中取消注释引用，例如：

```markdown
![chatting-tree 时间轴](docs/screenshot-timeline.png)
```

建议至少两张：

1. `screenshot-timeline.png` —— 右侧栏里的决策时间轴（含打勾的已选分支）。
2. `screenshot-lineage.png` —— 顶部的会话血缘树与一个分叉出来的子会话。

截图时请把窗口拉宽到 1280px 以上（窄于约 1250px 时帧布局不给右侧栏轨道，会改走浮层抽屉），
并确认面板头部的版本号可见 —— 那既是校验也是版本痕迹。
